## 🏥 Key Features

- **Luxury Aesthetic Design**: Built with Playfair Display typography, HSL tailored gold & obsidian palette, micro-animations, and responsive layout.
- **Patient Reviews & Real-Time Ratings**: Interactive 5-star review system with instant publishing via localStorage.
- **VIP Consultation Booking**: Intuitive triage booking flow for London Mayfair & Dubai DIFC suites.
- **Clinic Member Portal (`portal.html`)**:
  - Secure clinician login gate (PIN / Passcode protected).
  - Patient consultation triage queue.
  - Live status updates and automated SMS dispatch simulation.
  - Seamless navigation back to the main website from footer and dashboard.

## 💻 Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/jyothiskv807-sys/Firtst-project.git
   cd Firtst-project
   ```

2. Start the local server:
   ```bash
   npm start
   # or
   node server.js
   ```

3. Open in browser:
   - Main site: `http://localhost:3000/`
   - Staff portal: `http://localhost:3000/portal.html`
